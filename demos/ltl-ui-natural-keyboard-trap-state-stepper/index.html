When Tab inserts text instead of moving focus

A text editor can use Tab for indentation. This example explains what happens when that key is handled inside the editor, and what an accessibility check still needs to establish.

What this example establishes. This is an illustrated explanation of the saved text-editor example, not an executed test or a complete check of all exit methods. Tab inserting indentation is permitted when the user can still leave by keyboard and is told about any nonstandard exit method. Read the W3C explanation.
