What each method contributes across these demos

Agent is easier to use for impact

It is strongest when the evidence is a long user journey: focus walking through background content, controls becoming practically unreachable, or a bug preventing task completion.

LTL is easier to use for exact covered boundaries

It is strongest when the AP already has a precise temporal contract: after activation or Escape, it identifies the exact element or modal, waits a bounded interval, and emits a compact witness.

Together they answer different questions

LTL answers “did this formal obligation fail, exactly where?” The Agent answers “what does that failure do to a keyboard user in the complete workflow?”
