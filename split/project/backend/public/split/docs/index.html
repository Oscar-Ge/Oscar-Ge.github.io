01 · REAL DATA

344 笔历史记录，逐人对账

317 笔支出、27 笔还款，总支出 $35,241.21。导入保留日期、付款人、分摊与备注。姓名由 zhao 修正为 wenchao zhang，原成员 ID 与账务归属保留。

02 · MONEY CORRECTNESS

把半分钱留到结算时处理

总金额使用整数分；分摊保留 microcent 精度。每笔分摊严格守恒，汇总后统一舍入，确保所有人的余额之和为零。

03 · COLLABORATION

多人编辑，也不会相互覆盖

每次读取带有 revision。写入在事务中保存历史快照并校验版本；旧版本返回 409 Conflict，界面保留草稿并提示刷新核对。

04 · AUTOMATION

房租每月记，重复运行只记一次

服务器使用纽约时区判断到期月份，以 rent-YYYY-MM 为稳定 ID。GitHub Actions 按月触发，云端任务核对并重试失败；已删除的自动记录不会被重新创建。
