Learning from interface use

Learn from how people use generated interfaces.

Watching people use a generated interface can reveal confusing controls, missing feedback, and broken task flows.

RELIEF turns those observations into training data. A coding agent revises the interface using feedback. RELIEF then reconstructs a generation trace that would produce the revised interface and uses it to fine-tune the model.

From revisions to supervision

Reconstruct how the improved interface could have been generated.

The revised website provides a target. RELIEF connects its changes back to the original generation steps.

  1. Replay. Record the website source after each file-writing step in the original generation trace.
  2. Attribute and patch. Use code differences and Git-blame-style attribution to identify and revise the steps responsible for changed code.
  3. Verify and train. Replay the reconstructed trace to check that it reproduces the revised website, then use it for supervised fine-tuning.
Training and reconstruction details

We fine-tuned a separate variant of each base model for each feedback source using reconstructed generation traces. The experiments used supervised fine-tuning with LoRA adapters. Reconstruction retained the original reasoning while revising code-writing actions; see Sections 4 and 6 of the paper for the procedure and its limitations.

Abstract

Code generation models are increasingly used to produce interactive artifacts, such as websites and user interfaces. Many properties that determine whether these interfaces are useful only become apparent through realistic interaction, making them difficult to incorporate into model training. In this paper, we introduce RELIEF (REvision-based Learning from Interactive Experience and Feedback), a method for improving code generation models using feedback on their generated interfaces. RELIEF uses a coding agent to revise these interfaces, then incorporates the improvements into their original generation traces to produce supervision for fine-tuning. To evaluate RELIEF, we collected a dataset of 200 synthetically generated websites paired with 355 interaction recordings and accompanying feedback from 24 users. We used critiques derived from code inspection, automated interaction, explicit human feedback, and human interaction recordings to fine-tune variants of two code generation models. Our results show that feedback effectiveness varies with base model capabilities, with critiques inferred from human interaction recordings leading to the largest usability improvements overall under our tested models.
